## 二、设计系统审查

### 2.1 Token 体系 (良好)

系统建立了完善的 SCSS Token 体系，涵盖：

- **颜色 token** — 完整的语义色、品牌色、背景色、文字色 (colors.scss)
- **字体 token** — Inter 为主，含 Display 层级、负字距 (typography.scss)
- **间距 token** — 4dp/8dp 栅格 + 12dp 层 (spacing.scss)  
- **阴影 token** — 5 级层次 + 品牌色光晕 (shadows.scss)
- **动效 token** — 时长 + 缓动 + 交互过渡 + reduces-motion 支持 (motion.scss)
- **布局 token** — 圆角/容器/侧边栏/头部/z-index (layout.scss)

> **亮点**: `--ease-spring` 缓动、`prefers-reduced-motion` @media 查询、`
> **问题**: 部分页面仍使用硬编码色值而非 CSS 变量（查看 dashboard 的 `COLORS` 对象中硬编码了 `#0369A1`、`#D97706` 等，主色已升级为 `#2563EB` 但 dashboard 中的颜色常量未更新）

### 2.2 字体加载

Inter 字体声明存在，**但** `@font-face` 声明或 `font-display: swap` 可能缺失。需要确认 `index.html` 或 `main.ts` 中是否通过 Google Fonts/subset 加载了 Inter。

### 2.3 暗黑模式

- ⚠️ 未发现暗黑模式支持。所有颜色 token 仅在 `:root` 中声明，没有 `[data-theme="dark"]` 或 `@media (prefers-color-scheme: dark)` 变体
- 侧边栏使用海军蓝 (`#0F172A`) 但内容区使用白色表面，暗色模式下（Dashboard 的 `pieOption` tooltip 使用 `rgba(15, 23, 42, 0.92)` 背景，是深色背景硬编码而非主题变量）
